Classroom 50 · GitHub Workflow

How Programming Assignments Work

Every student receives a private GitHub repository inside asu-cse with starter code, automated GitHub Actions grading, and an open Feedback Pull Request.

STEP 01 · JOIN ORG

Accept Your Organization Invite

Accept the invitation sent by your instructor via email, at github.com/asu-cse, or on classroom50.org to join the student team.

STEP 02 · ACCEPT

Generate Your Personal Repository

Open the assignment acceptance link shared by your instructor (or run gh student accept) to provision your private repository.

STEP 03 · CODE & PUSH

Edit Allowed Files & Push to Main

Clone your personal repo, implement your solution in the allowed source files (such as hello.cpp), test with g++, and git push.

STEP 04 · REVIEW

Check Release Scores & Feedback PR

View your automated test breakdown on GitHub Releases and read line-by-line TA and instructor review comments in Pull Request #1.
